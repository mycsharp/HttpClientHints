# Security Policy

## Reporting a vulnerability

Do not report security vulnerabilities in public GitHub issues.

Report them privately through [GitHub private vulnerability reporting](https://github.com/mycsharp/HttpClientHints/security/advisories/new). Only the maintainers can see the report. Please include the affected package and version, a description of the issue and, if possible, steps to reproduce it.

Fixes are released as new versions of the NuGet packages `MyCSharp.HttpClientHints` and `MyCSharp.HttpClientHints.AspNetCore`.

## Other bugs

Report bugs that are not security vulnerabilities in [GitHub issues](https://github.com/mycsharp/HttpClientHints/issues).
